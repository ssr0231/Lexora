# Lexora — User Stories

**Version:** 0.1  
**Project:** Lexora

---

## Compliance Executive

### US-01 — Login

As a Compliance Executive, I want to securely log in to Lexora so that I can access my authorized clients and research.

### US-02 — View Clients

As a Compliance Executive, I want to see my assigned clients so that I can choose the client I am researching.

### US-03 — View Client Context

As a Compliance Executive, I want to view relevant information about a client so that I can understand the context before performing research.

### US-04 — Ask General Question

As a Compliance Executive, I want to ask a general GST question without selecting a client so that I can research regulatory information that is not client-specific.

### US-05 — Ask Client-Specific Question

As a Compliance Executive, I want to select a client and ask a question so that Lexora can consider the client's information while researching the regulation.

### US-06 — View Evidence

As a Compliance Executive, I want to see the regulatory sources supporting an answer so that I can verify the information myself.

### US-07 — Inspect Citation

As a Compliance Executive, I want to open the cited document and relevant page so that I can inspect the original source.

### US-08 — Ask Follow-Up

As a Compliance Executive, I want to ask follow-up questions in the same research session so that I don't have to repeat the context of my research.

### US-09 — Handle Uncertainty

As a Compliance Executive, I want Lexora to tell me when it does not have sufficient evidence so that I don't mistake an unsupported answer for reliable information.

### US-10 — View Research History

As a Compliance Executive, I want to revisit my previous research sessions so that I can continue or review earlier work.

---

## Senior CA

### US-11 — Review Research

As a Senior CA, I want to review research performed by employees so that I can verify important regulatory conclusions.

### US-12 — Provide Feedback

As a Senior CA, I want to provide feedback on research answers so that employees can correct or improve their work.

---

## Administrator

### US-13 — Manage Users

As an Administrator, I want to manage user accounts and roles so that access to Lexora remains controlled.

### US-14 — Assign Clients

As an Administrator, I want to assign users to clients so that employees only access the clients they are responsible for.

### US-15 — Manage Documents

As an Administrator, I want to upload and manage regulatory documents so that Lexora's knowledge base remains useful and current.
